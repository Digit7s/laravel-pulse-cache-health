# Security Policy

## Supported versions

This package is in pre-release development and has no stable releases yet. Until a stable support policy is published, security fixes will be made on the current `main` development branch. Support for released versions will be documented when releases are available.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public GitHub Issues or Discussions. Use GitHub's **Report a vulnerability** feature on this repository's Security page. Private vulnerability reporting is enabled for this repository.

If that private reporting option is unavailable, open an issue only to request a private reporting contact. Do not include vulnerability details, proof of concept, or sensitive information in that issue.
